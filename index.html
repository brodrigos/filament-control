Klipper / Moonraker Integration — USD Tracking

Filament3D

Monitoramento em tempo real do consumo de filamento da sua impressora 3D rodando Klipper (ex: 192.168.1.101:85). Cálculo automático em USD ($), gerenciamento de bobinas e débito automático em impressões concluídas ou canceladas.

Ver no GitHub Instalar no Linux

Monitoramento em Tempo Real

Conexão direta com o Moonraker (IP:Port) para ler o estado atual da impressora, arquivo em execução, progresso e filamento usado no job.

Cálculo em USD ($)

Cada bobina cadastra preço de compra em USD. O sistema calcula automaticamente o custo proporcional de cada impressão com base no peso líquido.

Débito Automático

Ao detectar mudança de estado (printing → complete / cancelled), o sistema debita automaticamente o filamento consumido no rolo ativo.

Dashboard Interativo

Visualização em tempo real dos rolos ativos, histórico completo de consumo, resumo financeiro e controle de bobinas — tudo integrado ao seu servidor de impressão.

Instalação no Linux

Copie o repositório para o host da impressora e execute o script automático.

git clone https://github.com/brodrigos/filament-control.git
cd filament-control
chmod +x install-script.sh
bash install-script.sh

Cria o serviço filament-control com Systemd, reinicia automaticamente e monitora o Moonraker na porta 3030.
